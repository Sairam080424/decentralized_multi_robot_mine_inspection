# Module 2.2: Capability Management

## 1. Module Overview
Module 2.2 provides semantic capability modeling, distributed capability exchange, constraint-based task-to-robot matching, and real-time resource accounting across the multi-robot fleet.

## 2. Submodule Index
- [2.2.1 Capability Model](capability_model.md): Semantic schema declaring mobility types, sensor payloads, and certified operations.
- [2.2.2 Capability Exchange](capability_exchange.md): P2P capability advertisement, delta updates, and distributed caching.
- [2.2.3 Capability Matching](capability_matching.md): Constraint solver matching mission task requirements against robot capability sets.
- [2.2.4 Resource Availability](resource_availability.md): Dynamic accounting of battery watt-hours, compute headroom, and operational payload availability.

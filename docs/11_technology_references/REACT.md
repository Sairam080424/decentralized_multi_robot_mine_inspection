# Technology Evaluation: React 18+ with TypeScript & Deck.gl

## 1. Purpose
Modern component-based web framework for industrial operator dashboards and GPU-accelerated map rendering.

## 2. Relevant Modules
Module 3.4 Monitoring and Visualization.

## 3. Installation Requirements
- **Prerequisites**: Node.js 18+ and npm / pnpm.

## 4. ROS 2 Compatibility
- **Compatibility Status**: `Connects to ROS 2 backend via WebSockets / REST API.`

## 5. Advantages
Rich visualization ecosystem (Deck.gl, Visx, ReactFlow), strong typing, cross-platform tablet support.

## 6. Limitations
Requires web development tooling separate from C++/CMake build chains.

## 7. Adoption Decision
- **Status**: `ADOPTED`
- **Architectural Rationale**: Adopted for the operator surface dashboard, visual mission editor, and real-time mine map visualizer.

# Testing and Validation Strategy

This directory defines the multi-tier testing framework, test suites, fault-injection procedures, and quantitative acceptance benchmarks for the platform.

## Documents
- [TEST_STRATEGY.md](TEST_STRATEGY.md): Testing philosophy, test automation pipeline, and test matrices.
- [UNIT_TESTING.md](UNIT_TESTING.md): Unit test specifications for algorithms, CRDTs, and state machines.
- [INTEGRATION_TESTING.md](INTEGRATION_TESTING.md): Inter-module and inter-layer ROS 2 integration test suites.
- [SYSTEM_TESTING.md](SYSTEM_TESTING.md): End-to-end multi-robot mission scenarios in simulated mine tunnels.
- [FAULT_INJECTION_TESTING.md](FAULT_INJECTION_TESTING.md): Stress testing: RF loss, packet drop, and robot crash recoveries.
- [PERFORMANCE_METRICS.md](PERFORMANCE_METRICS.md): Key Performance Indicators (KPIs) and proposed target thresholds.

# Module 1.1: Simulation Environment

## 1. Module Overview
Module 1.1 provides the subterranean virtual testing ground for the multi-robot platform. It models realistic underground mine geometry, tunnels, uneven terrain, structural obstacles, hazards, and simulated wireless mesh communication degradation using Gazebo Sim.

## 2. Submodule Index
- [1.1.1 Mine World](mine_world.md): Multi-level mine drift geometry, adits, cross-cuts, and subterranean lighting.
- [1.1.2 Tunnel Generation](tunnel_generation.md): Procedural and modular SDF tunnel segments with realistic irregular rock surfaces.
- [1.1.3 Obstacle Modelling](obstacle_modelling.md): Static and dynamic obstacles: rock piles, fallen timbers, abandoned equipment, rail tracks.
- [1.1.4 Hazard Modelling](hazard_modelling.md): Simulated hot spots (overheating transformers/bearings), structural cracks, and simulated gas hazard zones.
- [1.1.5 Communication Environment Simulation](communication_simulation.md): Simulated wireless mesh attenuation, distance-dependent packet drop, and subterranean non-line-of-sight RF degradation.

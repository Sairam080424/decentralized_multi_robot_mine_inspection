# Module 3.2: Mission Management

## 1. Module Overview
Module 3.2 oversees mission dispatching, live progress monitoring, mission execution state tracking, and historical audit trail recording.

## 2. Submodule Index
- [3.2.1 Mission Submission](mission_submission.md): Dispatching validated mission manifests to the subterranean robot mesh.
- [3.2.2 Mission Progress](mission_progress.md): Aggregating distributed task completions into overall percent-complete and ETA metrics.
- [3.2.3 Mission Status](mission_status.md): Managing high-level mission states (`DRAFT`, `SUBMITTED`, `IN_PROGRESS`, `PAUSED`, `COMPLETED`).
- [3.2.4 Mission History](mission_history.md): Immutable audit logging of mission definitions, allocations, execution timelines, and interventions.

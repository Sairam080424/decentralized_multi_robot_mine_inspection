# Module 3.5: Data and Reporting

## 1. Module Overview
Module 3.5 manages persistent mission and inspection databases, scalable object storage for multi-modal evidence blobs, and automated PDF/HTML compliance report generation for mine safety engineers.

## 2. Submodule Index
- [3.5.1 Mission Database](mission_database.md): Relational PostgreSQL schema for missions, tasks, robots, and events.
- [3.5.2 Inspection Database](inspection_database.md): Time-series and asset-centric schema for inspection measurements and ratings.
- [3.5.3 Evidence Storage](evidence_storage.md): Scalable S3-compatible object storage (MinIO) for images, thermal grids, and point clouds.
- [3.5.4 Report Generation](report_generation.md): Automated PDF and HTML comprehensive inspection report generation.

# Module 3.1: Mission Planning

## 1. Module Overview
Module 3.1 provides the mission authoring tools, inspection objective definitions, atomic task parameterization, and static graph validation logic.

## 2. Submodule Index
- [3.1.1 Mission Creation](mission_creation.md): Declarative mission definition via JSON/YAML manifests or visual web editor.
- [3.1.2 Inspection Objectives](inspection_objectives.md): Defining subterranean inspection targets (roof bolts, conveyor bearings, electrical substations).
- [3.1.3 Task Definition](task_definition.md): Parameterizing tasks (waypoint coordinates, required sensor modalities, dwell times).
- [3.1.4 Mission Validation](mission_validation.md): Static verification: DAG cycle detection, reachable capability checking, hazard parameter validation.

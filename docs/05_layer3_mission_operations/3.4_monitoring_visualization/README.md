# Module 3.4: Monitoring and Visualization

## 1. Module Overview
Module 3.4 provides the operator graphical interfaces, 2D/3D subterranean mine map rendering, live robot trajectory tracking, distributed task auction visualization, and communication health topology graphs.

## 2. Submodule Index
- [3.4.1 Mine Map Visualization](mine_map_visualization.md): 2D occupancy grid and 3D point cloud rendering; multi-robot map overlays.
- [3.4.2 Robot Position](robot_position.md): Live position and historical trajectory trails of Robot A and B with covariance ellipses.
- [3.4.3 Task Allocation View](task_allocation_view.md): Real-time Gantt charts, task assignment graphs, and auction bid visualization.
- [3.4.4 Robot Health](robot_health.md): Telemetry gauges (battery SoC, motor currents, CPU temperatures, storage utilization).
- [3.4.5 Communication Status](communication_status.md): P2P network mesh topology graph, link RSSI, packet loss, and routing hops.

# Module 3.6: External Integration

## 1. Module Overview
Module 3.6 provides public integration interfaces for external enterprise systems: a Python Public SDK, OpenAPI 3.0 REST endpoints, third-party robot manufacturer adapters, and enterprise asset management (IBM Maximo / SAP PM) connectors.

## 2. Submodule Index
- [3.6.1 Public SDK](public_sdk.md): Python and C++ client library for programmatic mission creation, status queries, and data extraction.
- [3.6.2 Mission APIs](mission_apis.md): OpenAPI 3.0 REST and WebSocket specifications for enterprise dispatch and telemetry.
- [3.6.3 Robot Manufacturer Adapters](robot_manufacturer_adapters.md): Hardware Abstraction Layer (HAL) adapters for third-party OEM robots.
- [3.6.4 Asset Management Integration](asset_management_integration.md): Connectors for enterprise maintenance systems (IBM Maximo, SAP PM, CSV export).

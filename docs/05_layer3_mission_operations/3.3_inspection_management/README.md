# Module 3.3: Inspection Management

## 1. Module Overview
Module 3.3 manages inspection target asset registries, visual RGB inspection evidence, radiometric thermal evidence, environmental hazard logs, and consolidated PASS/WARN/FAIL inspection scorecards.

## 2. Submodule Index
- [3.3.1 Inspection Point Management](inspection_point_management.md): Asset inspection registry, survey baselines, and coordinate frames.
- [3.3.2 Visual Evidence](visual_evidence.md): Optical RGB image metadata, EXIF geotagging, feature extraction for crack analysis.
- [3.3.3 Thermal Evidence](thermal_evidence.md): Radiometric thermal matrices, temperature profiling, and hotspot characterization.
- [3.3.4 Hazard Records](hazard_records.md): Logging structural fractures, water pooling, methane gas alerts, and rockfall hazards.
- [3.3.5 Inspection Results](inspection_results.md): Consolidated scorecard generation, threshold comparison, and sign-off workflows.

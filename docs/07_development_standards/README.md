# Development Guidelines and Setup

This directory contains instructions, standards, and workflows for engineering personnel contributing to the Decentralized Multi-Robot Mine Inspection Platform.

## Documents
- [DEVELOPMENT_SETUP.md](DEVELOPMENT_SETUP.md): Host machine prerequisites, Ubuntu 22.04 LTS, ROS 2 Humble, and Gazebo Sim setup.
- [CODING_STANDARDS.md](CODING_STANDARDS.md): C++17/20, Python 3.10, ROS 2 conventions, linting, and style enforcement.
- [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md): Colcon workspace build flags, symlink-install, and dependency resolution.
- [TESTING_GUIDELINES.md](TESTING_GUIDELINES.md): Unit testing (GTest/pytest), integration tests, and coverage thresholds.
- [GIT_WORKFLOW.md](GIT_WORKFLOW.md): Branching model, Conventional Commits, pull request reviews, and GitHub workflows.
